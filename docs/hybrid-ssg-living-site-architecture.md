## 1. Executive Summary & Vision

The goal is to provide a **"Living Static Site" (Hybrid SSG + ISR)** for all websites generated by the Revyme builder.

Websites built with Revyme must combine:
1. **Instant Speed (0–20ms)**: Every known page and route is pre-rendered at build time as static HTML and RSC payloads (`generateStaticParams`).
2. **Autonomous Content Management (Zero Rebuilds)**: Content editors adding new articles, tattoos, categories, or placements in Directus/Headless CMS must see their changes go live **instantly** without triggering a full project rebuild.
3. **Dynamic Interface Adaptation**: Navigation menus, dropdowns, and overlays adapt to new collection items in real time while maintaining 0ms initial render speed (zero layout shift).

## 3. Detailed Architecture Specifications

### Pillar A: Universal Route Discovery & `generateStaticParams` (Builder Core)

#### Problem Solved:
Historically, Revyme only injected `generateStaticParams` into `/[slug]/page.tsx`. Multi-segment routes (e.g., `/gallery/[category]/[place]/page.tsx`) or custom single-parameter routes (e.g., `/[category]/page.tsx`) were omitted, leaving them as dynamic SSR with 300–800ms delays on first navigation.

#### Architecture:
1. **Dynamic Route Detection**:
   Inspect all page routes matching `(path.endsWith('/page.tsx') || path === 'app/page.tsx') && /\[[a-zA-Z0-9_.-]+\]/.test(path)`.
   Extract parameters preserving order: `['category', 'place']`.
2. **Three-Tier Parameter Discovery Pipeline** (`cms-seo.ts:discoverDynamicRouteParams`):
   - **Tier 1 (Project Link Crawler)**: Scans all JSX/TSX files for static `href="/path"`, dynamic string concatenation (`href={"/prefix/" + item.slug}`), and template literals.
   - **Tier 2 (Segment Matching)**: Matches known URLs against route segments (exact matches for full combinations, prefix matches for intermediate segments like `category`).
   - **Tier 3 (Collection Cartesian Synthesis)**: Cross-combines known values with matching collections (e.g., `category` values `['men', 'women']` × `placements` items).
3. **Safe Invariant**:
   Always emit:
   ```tsx
   export const dynamicParams = true;
   ```
   Ensures that if any URL is not captured in `generateStaticParams`, Next.js renders it on-demand (ISR) rather than throwing a 404.
4. **Locale Wrappers**:
   Any `isLocaleRouteFile` must re-export:
   ```tsx
   export { default, generateStaticParams } from '@/app/...';
   ```

### Pillar B: On-Demand Cache Revalidation (`app/api/revalidate/route.ts`)

#### Goal:
Allow Directus to notify the live Next.js server when records are created, updated, or deleted so cache is purged in real time without waiting for `revalidate: 14400` TTL or running a rebuild.

#### Implementation:
Generate `app/api/revalidate/route.ts` during export:

```typescript
import { NextRequest, NextResponse } from 'next/server';
import { revalidatePath, revalidateTag } from 'next/cache';

export async function POST(req: NextRequest) {
  const secret = req.nextUrl.searchParams.get('secret') || req.headers.get('x-revalidate-secret');
  const expectedSecret = process.env.REVALIDATION_SECRET || 'revyme-revalidate-token';

  if (secret !== expectedSecret) {
    return NextResponse.json({ message: 'Invalid secret token' }, { status: 401 });
  }

  try {
    const body = await req.json().catch(() => ({}));
    const { path, tag, collection } = body;

    if (path) {
      revalidatePath(path);
      return NextResponse.json({ revalidated: true, path, now: Date.now() });
    }

    if (tag) {
      revalidateTag(tag);
      return NextResponse.json({ revalidated: true, tag, now: Date.now() });
    }

    // Directus webhook collection mapping
    if (collection) {
      // Invalidate collection tags or associated layout
      revalidatePath('/', 'layout');
      return NextResponse.json({ revalidated: true, collection, now: Date.now() });
    }

    // Fallback: revalidate layout
    revalidatePath('/', 'layout');
    return NextResponse.json({ revalidated: true, fallback: true, now: Date.now() });
  } catch (err: any) {
    return NextResponse.json({ message: err?.message || 'Revalidation failed' }, { status: 500 });
  }
}
```

### Pillar C: Component & Overlay Data Strategy: Dynamic Mode vs Hybrid SSG

#### Problem:
Client components (like `Navbar.tsx` or design component overlays) currently import `@/cms/placements.json`.
- In **Hybrid SSG Mode**: When a new item is added to Directus, the link doesn't appear in the dropdown until a re-sync + rebuild unless client revalidation is used.
- In **Dynamic Mode (`buildMode: 'dynamic'` or `ssg: false`)**: The user expects the entire site to be 100% dynamic, pulling fresh data directly from Directus on every visit. However, because components like `Navbar.tsx` are client components with hardcoded imports to `@/cms/placements.json`, the overlay menu remains frozen at export time and violates the contract of Dynamic Mode!

#### Architecture by Build Mode:

##### 1. Dynamic Mode (`buildMode: 'dynamic'` or `ssg: false`): Direct API Query
In Dynamic Mode, the export pipeline in `source-export.ts` must strip static `@/cms/*.json` imports from components and overlays (just like it already does for `page.client.tsx`). Instead, it injects a **direct live fetch**:

```tsx
'use client';

import React, { useState, useEffect } from 'react';

export default function Navbar() {
  // Dynamic Mode: Always pull fresh records directly from the live API
  const [placements, setPlacements] = useState<any[]>([]);
  const [isLoading, setIsLoading] = useState(true);

  useEffect(() => {
    let active = true;
    async function fetchLivePlacements() {
      try {
        const res = await fetch('/api/cms/query?source=placements', {
          cache: 'no-store', // Always bypass cache in Dynamic Mode
        });
        if (res.ok) {
          const fresh = await res.json();
          if (active && Array.isArray(fresh)) {
            setPlacements(fresh);
          }
        }
      } catch (err) {
        console.error('Failed to load dynamic overlay collection:', err);
      } finally {
        if (active) setIsLoading(false);
      }
    }
    fetchLivePlacements();
    return () => { active = false; };
  }, []);

  // Render navigation using live `placements`
}
```

##### 2. Hybrid SSG Mode (`buildMode: 'hybrid'` or `ssg: true`): Stale-While-Revalidate (SWR)
In Hybrid SSG Mode, we want **instant 0ms initial paint** (zero layout shift) combined with seamless background updates:

```tsx
'use client';

import React, { useState, useEffect } from 'react';
import initialPlacements from '@/cms/placements.json'; // 0ms initial render snapshot

export default function Navbar() {
  const [placements, setPlacements] = useState(initialPlacements);

  useEffect(() => {
    let active = true;
    async function refreshPlacements() {
      try {
        const res = await fetch('/api/cms/query?source=placements', {
          headers: { 'Cache-Control': 'no-cache' },
        });
        if (res.ok) {
          const fresh = await res.json();
          if (active && Array.isArray(fresh) && fresh.length > 0) {
            setPlacements(fresh);
          }
        }
      } catch {
        // Graceful fallback to initialPlacements
      }
    }
    refreshPlacements();
    return () => { active = false; };
  }, []);

  // Render navigation using `placements`
}
```

#### Key Guarantees:
1. **Dynamic Mode Accuracy**: In Dynamic Mode, every visitor sees 100% real-time data from Directus without build-time stale snapshots anywhere on the site.
2. **Hybrid SSG Speed**: In Hybrid SSG, 0ms initial paint with zero layout shift, silently updated in the background.
3. **Immediate Routing**: When clicked, any new item (`/gallery/men/new-place`) is rendered on-demand on the server (`dynamicParams = true`).

## 5. Verification & Acceptance Criteria

1. **Build Output**:
   Running `next build` on a project with dynamic routes outputs:
   ```text
   ● /gallery/[category]                   (SSG)
   ● /gallery/[category]/[place]           (SSG)
   ● /tattoos/[slug]                       (SSG)
   ```

   `curl -I http://localhost:3000/gallery/men/peredplichcha` returns `x-nextjs-prerender: 1` and `x-nextjs-cache: HIT`.
3. **On-Demand Verification**:
   Requesting a previously unrendered valid slug triggers an on-demand render with HTTP 200, caches it, and serves subsequent requests in `< 25ms`.
4. **Zero Rebuild Daily Operations**:
   Creating, editing, and deleting records in Directus updates the live website within seconds via `/api/revalidate` and client SWR.
